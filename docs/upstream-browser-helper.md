# 上游网站批量连接与授权

用户希望在一个页面连接所有保存的上游网站、统一授权读取，不再逐站点击书签。普通网页无法执行外站读取，因此使用一次安装的 Chrome / Edge 扩展；站点的登录、验证码和 Google 登录仍由用户本人完成。

## 使用

1. 在上游渠道页面点击“一键连接”，按指引下载并解压助手。
2. 在 `chrome://extensions` 或 `edge://extensions` 开启开发者模式，加载已解压的扩展目录。
3. 刷新 hwjai 页面。点击“一键连接”，复用现有网站标签页与浏览器登录。
4. 点击“一键授权”。首次访问或添加新的域名时，扩展列出本批网站，一次允许域名访问。已有域名访问权时直接读取。
5. 逐站显示读取及保存结果。需要登录、展开 Key 或完成验证的网站单独处理，再重新授权即可。

余额刷新和“读取已有 Key”自动优先使用助手，未安装助手时保留原有书签连接。金额以人民币读取，Key 累计消费和网站余额独立保存；余额刷新不会更改 Key、模型、报价或上架状态。

## 边界

- 仅 `https://hwjai.me`、本地 `http://127.0.0.1:3001` 与 `http://localhost:3001` 的顶层页面能发起请求。
- 上游仅接受明确允许的 HTTPS 域名，余额页必须与 Key 页面同源；页面跳转后再次核对来源。
- 复用自包含的 `discoverUpstreamPage`，只读已有 Key、已加入线路、报价和金额。读取 Key 的展示接口及会话刷新接口可能使用 POST，不创建或编辑 Key。
- 不使用 cookies、webRequest 权限。Cookie 留在上游浏览器环境；读取结果仅返回请求对应的 hwjai 标签页，不放入扩展持久存储。
- 扩展临时会话存储仅包含待授权网站配置和请求标识；授权后删除该请求。关闭页面、过期请求、拒绝访问均不伪造成功。
- 仅在用户点击时连接或读取；不会后台扫描任意网站。未知页面可继续使用原有页面选择、书签流程，不能保证所有网站都能读取隐藏的 Key。

## 构建与交付

当前 Windows 部署环境，在 `web` 运行 `node scripts/build-upstream-extension.mjs`，编译通用读取器和扩展核心，复制许可文件，生成 `web/public/downloads/hwjai-upstream-helper.zip`。随后执行正常前端生产构建，ZIP 随现有 3001 服务发布。源码基于 new-api / QuantumNous，保留 AGPL-3.0 许可。

扩展源码更新后需要重新打包；已安装的开发者扩展需要在浏览器扩展页重新加载。助手不会通过脚本改动用户的浏览器设置或安装扩展。

助手 1.0.1 增加 Sub2API（包括 pqai.cc）兼容：复用页面已有的 bearer 会话，只在同源 `/api/v1/` 接口使用；读取现有 Key 列表和只读详情、账户可用余额，以及网站 Key 表格使用的实际累计消费查询。界面的省略号 Key 不作为完整 Key 导入，`quota_used` 不替代累计消费。金额按已有展示约定使用原始数值，不额外换汇；登录凭证不返回 hwjai，也不写入扩展存储。

从旧版本升级时，重新下载并解压助手，覆盖原加载目录，在 `chrome://extensions` 或 `edge://extensions` 点击重新加载，刷新 hwjai 后对 pqai 重新授权。仅刷新网站不会更新已加载的扩展代码。

助手 1.0.2 同时读取登录后的 Sub2API 模型广场与账号专属分组倍率，按 Key 的分组 ID 匹配其模型单价；不借用同名分组、其他模型或官方参考价。账户倍率必须单独核实，且只应用一次。支持按次价格及整单上下文阶梯的 Token 价格，缓存读、5 分钟写入和 1 小时写入分别保留。尚未完整支持的时段、峰值或请求附加定价继续显示具体核实提示。重新授权带来的分组或价格变化会刷新待审核报价，已上架售价仍按原有保护规则保存。

2026-10-12 核实 pqai 的已登录授权数据：Key 的 CCMAX20 分组 ID 为 3，而模型广场成功响应只含分组 6 和 27。用户确认同模型跨站原价一致，服务器可复用已读取的完整 Token 原价合同，再通过当前 Key 的 `/v1/sub2api/billing` 读取实际倍率；不能从名称推算倍率，也不能借用其他站采购价或本地售价。

助手 1.0.3 增加读取登录后的 `/api/v1/groups/available`，保存按 Key 分组 ID 匹配的图片1K/2K/4K单价及图片独立倍率。图片生成使用该分组的按张合同，不能复用共享 Token 原价。分辨率价格相同的合同显示“每张”；缺少分辨率价格、价格不同或倍率无法核实时保留已有售价并阻止未经确认的上架。下载入口使用 `/downloads/hwjai-upstream-helper-1.0.3.zip`，避免旧 ZIP 缓存；旧助手授权图片分组时需更新后重新读取。

2026-10-17 核实 lunoru.cc：已有 Key 授权有效，但 `/api/v1/model-plaza` 返回 404，授权快照的 `catalog` 为 `null`。服务器支持用已保存 Key 实时读取 `/v1/models` 和 `/v1/sub2api/billing`，将已确认的同模型共享 Token 原价合同与当前 Key 的有效倍率组合，无需为缺失的模型广场反复授权。此路径不延长旧浏览器快照的有效期；旧图片分组合同、无共享原价的模型、未能确认的实时倍率继续阻止上架。已有完整价格快照仍遵守原有时效检查，已上架售价不随报价刷新自动变化。
